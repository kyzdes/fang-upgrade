date  : 2026-08-14T17:48:17Z
cmd   : docker run --rm -e OPENFANG_SHUTDOWN_DRAIN_SECS=1e30 openfang:fang40b start

The value parses as an f64, so shutdown_drain_timeout() accepted it and handed
it to Duration::from_secs_f64, which panics on anything it cannot represent.
The call sits before axum::serve, i.e. on the START path, so the daemon dies on
the way up — the opposite of what the function's own doc-comment promised
("ignored rather than fatal ... this runs on the shutdown path").
