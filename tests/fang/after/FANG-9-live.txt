########## the false positive this live check caught ##########
# The FIRST patched build (before commit 2793923) answered the fabricator with:
#
#   "I failed to write the file because I lacked the necessary tool to perform
#    the write operation. No content was saved to output/live-fabricated.md.
#
#    [Unverified — nothing was written in this turn: the agent reported a
#    completed write, was challenged, and still called no writing tool. ...]"
#
# The model had already told the truth, and the runtime stamped it anyway: the
# second sentence carries a write verb and a path, and the negation list had
# every form of "not" except the bare "no". Nothing false was said — but a
# guard that annotates honest refusals is this defect with the sign flipped.
# "no"/"neither" joined the list, the live sentence became a unit test, and the
# run above is the same prompt against the corrected build.
